## [0.1.0](https://github.com/SCX-snow/otlp-trace-renderer-react/releases/tag/v0.1.0) (2026-09-29)

First release: a Jaeger-style OTLP trace timeline for React, split into a zero-dependency headless
core and a canvas renderer.

### Features

**Headless core — `@slcomplex/otlp-trace-renderer/headless` (no React, no DOM)**

- Canonical trace model (`TraceData` / `SpanData` / `ResourceData`) plus a structured
  `NormalizeWarning` union: `parent-not-found`, `negative-duration`, `cycle`, `empty-trace`,
  `duplicate-span-id`, `clock-skew`, `bad-timestamp`, `multiple-traces`. Warnings carry codes and
  parameters only; the UI layer turns them into sentences with `formatWarning()`.
- `normalizeTrace()`: absolute nanosecond timestamps are converted to trace-relative microseconds
  through BigInt deltas, so 1 µs stays exact even though the raw values exceed
  `Number.MAX_SAFE_INTEGER`. Deterministic ordering (start ascending, then duration descending, then
  spanId), duplicate detection, parent resolution, cycle breaking, and `roots` / `children` / `index`
  indexes.
- `flattenRows()`: tree → rows pre-order DFS over an explicit stack, so very deep chains (tested at
  20 000 levels) do not overflow; collapsed nodes stay visible but are not descended into.
- Viewport math: `toX` / `toT` / `fitViewport` / `clampViewport` / `zoomAt` / `panByPx` /
  `revealRange` / `maxSpanUs` with clamping constants (`MIN_SPAN_US`, `MAX_SPAN_RATIO`,
  `OVERSCROLL_RATIO`). NaN and ±Infinity are clamped, and unchanged values keep their object
  identity so the reducer can skip re-renders.
- Hit testing: `rowAtY` (O(1), scroll-aware, the sticky ruler band never hits a row), `barRange`,
  `hitTest`. Bar x-positions depend on time only — tree depth is expressed by the DOM name column,
  so grid lines and ticks stay aligned with every row.
- Interaction core: `resolveKeyCommand` (pure key → command mapping, Ctrl/Cmd/Alt combinations are
  left to the browser), `traceReducer` (pure reducer returning `[state, effects]`), `initViewState`,
  `rowsOf`, and selectors `spanAt` / `rowOfSpan` / `ancestorsOf` / `durationPercentile` /
  `precomputeDurations`.
- Time-axis and layout metrics: `resolveTimeAxis`, `DEFAULT_METRICS`, `resolveNameColumnWidth`,
  `MIN_PLOT_WIDTH`.
- Theme tokens: `TOKENS` (CSS variable names), `DEFAULT_THEME`, `DEFAULT_DARK_THEME`, `themeVar`.
- i18n: `MESSAGES`, `LOCALE_LABELS`, `resolveLocale`, `resolveMessages`, `format`, `formatWarning`,
  `describeWarning`, with `en` / `zh-CN` / `zh-TW` / `ja` built in.
- Formatting: `formatDurationUs` (Intl-aware, up to 3 significant digits) and `absoluteTime`.

**OTLP adapter — `@slcomplex/otlp-trace-renderer/adapters/otlp`**

- `normalizeOtlpTrace()` for OTLP/JSON (`{ resourceSpans: [...] }`): camelCase and snake_case field
  names, hex and protojson base64 ids normalised to lowercase hex, full `AnyValue` flattening
  (string / int / double / bool / bytes / array / kvlist, with integers beyond
  `Number.MAX_SAFE_INTEGER` preserved as strings), span kind and status mapping, span events
  converted to trace-relative microseconds, links, and `service.name` / scope name extraction.
- Multi-trace input selects `opts.traceId` (or the trace with the most spans) and records a
  `multiple-traces` warning.

**React — `@slcomplex/otlp-trace-renderer`**

- `TraceDetailView`: toolbar + timeline + detail panel, with controlled/uncontrolled
  `viewport` / `selectedSpanId` / `collapsedSpanIds` (each decided independently, `null` counts as
  controlled), `height`, `showToolbar` / `showDetailPanel`, `detailPanelHeight` (`flexShrink: 0`),
  `metrics`, `theme`, `servicePalette`, `spanColorMode` (`'service'` | `'duration'`), `zoomOnWheel`,
  `locale`, `messages`, `className` / `style`.
- Render slots: `renderToolbar`, `renderSpanDetail`, `renderSpanDetailActions`,
  `renderSpanDetailExtra`, `children`, plus the `TraceDetailViewApi` handed to slots
  (`select`, `focusSpan`, `zoomBy`, `fit`, `collapseAll`, `expandAll`, `state`, `dispatch`) and
  `useTraceMessages()` for slot-localized copy.
- Standalone components: `TraceTimeline`, `TraceToolbar`, `SpanDetailPanel`, `SpanNameColumn`.
- Rendering: canvas timeline with DPR-aware sizing, per-service colours with collision avoidance
  inside one trace (`SERVICE_PALETTE`, `SERVICE_PALETTE_DARK`) or duration-percentile colours, an
  error colour reserved for failed spans, a minimum bar width for zero-length spans, and a sticky
  ruler drawn after the bars so it always covers them.
- Interaction: click a bar or a name to select, double-click any row to collapse/expand, an explicit
  caret button left of each name, drag to pan, `Ctrl`/`Cmd` + wheel (or `zoomOnWheel`) to zoom around
  the pointer with click/drag disambiguation.
- Keyboard: `↑`/`↓` move the selection and scroll it into view, `←`/`→` collapse/expand
  (idempotent), `Shift + ←/→` pan by 25 % of the viewport, `+`/`-` (and `=` `_` `Add` `Subtract`)
  zoom around the viewport centre, `F` fit, `0` reset (fit + expand everything), `Esc` clear the
  selection, `Enter` move focus into the detail panel.
- Accessibility: `role="application"` with a localised label, `aria-expanded` on collapse carets,
  an `aria-live` selection announcement, and a focusable detail panel.
- Theming: `theme` is written as inline CSS variables on the root node only (never a global rule);
  default tokens are injected once as a zero-specificity `:where(:root)` rule and removed when the
  last instance unmounts. The canvas resolves the same variables via `getComputedStyle` and
  re-resolves on class / style / `data-theme` / `prefers-color-scheme` changes.

**Tooling and release**

- ESM-only build with tsup (`es2020`, `dist` + `.d.ts`), four exported subpaths
  (`.`, `./react`, `./headless`, `./adapters/otlp`) and `sideEffects: false`.
- Test suite: vitest across node and jsdom environments, including reducer/keyboard/hit-test/axis
  unit tests and full component tests.
- Real-browser regression suite (Playwright + chromium) covering first paint, dark preset, click and
  hover alignment after scrolling, touch input, flex layout at 5 000 rows, ruler draw order, caret
  placement and a clean console.
- Packaging gates: `publint`, `attw`, `size-limit` budgets, `verify:pack` (installs the real tarball
  into empty Vite projects on React 18 and 19, checks type resolution, tree-shaking and Node ESM
  import) and `verify-react19` (runs the whole test suite against React 19).
- CI (`ci.yml`): typecheck, lint, test, build, size, publint, attw, plus dedicated React 19, browser
  and pack jobs. Release (`publish.yml`): pushing a `vX.Y.Z` tag verifies the tag matches
  `package.json`, runs the gates, publishes to npm with provenance, and creates a GitHub Release.
- Storybook 10 with 13 stories, rendered in tests through `composeStories`.
- Examples: `examples/react-vite` (imports the package by name through the workspace link and
  supports `?spans=`, `?span=`, `?locale=`, `?theme=`) and `examples/headless-node` (headless
  computation in plain Node).

### Notes
